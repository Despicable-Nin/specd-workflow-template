## New Skill: skill-project-init.py
*   **Purpose:** To perform the mandatory, full initial system setup and project context binding when starting a fresh session or project. This acts as the project's operational *seed*.
*   **When to use:** ALWAYS. This MUST be the first skill called in every new project, session, or operational context switch.
*   **Inputs:** Target Project Name, Initial Scope (optional).
*   **Procedure:** Performs the following sequence:
    1.  Check for the WorkLedger and create the initial necessary status records (WORK-XXX: Project Seeded).
    2.  Call `skill-work-ledger-management` to seed the project's initial record.
    3.  Sets up the local working directory structure for the new project and creates the binding files.
*   Output: A fully initialized, state-tracked, and reusable project context.
*   Validation: Verify that the WorkLedger and the project's `binding.yaml` both contain the project's name and that the OS is declared "Operational."
