# Workflows Directory

Each workflow represents a defined, multi-step journey through the OS. These are the entry points for the user.

## Examples of Blueprints:

- `workflow_new_project.md`: Defines the full flow: Intake -> Discovery -> Constitution -> Architecture Calibration -> Specification Drafting -> Approval Gate.
- `workflow_new_feature.md`: Defines the core cycle: Specify -> Plan -> TDD/Implement -> Review -> Merge.
- `workflow_bug_fix.md`: A streamlined path triggered for small, known issues (still requires a lightweight specification).
- `workflow_migration.md`: Extended flow for major architectural shifts, incorporating gap analysis and iterative planning.
